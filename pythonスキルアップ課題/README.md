# Yahoo!ニュース(IT分野) RSS収集ツール

Yahoo!ニュースのITカテゴリRSSフィードから最新記事情報を取得し、Excelファイルに自動で蓄積していくPythonスクリプトです。

## できること

- RSSフィードから記事の「タイトル」「URL」「公開日時」を取得
- 取得結果をExcelファイル(`news_list.xlsx`)に保存
- 実行するたびに、既存データへ新しい記事を追記（同じ記事の重複は自動で排除）
- 見出し行の太字・列幅調整など、見やすい体裁に自動整形
- RSS取得に失敗した場合や、記事が0件だった場合も安全に処理を終了
- 出力先のExcelファイルが開いたまま実行された場合も、エラーで落ちずに分かりやすいメッセージを表示

## 使用技術

- Python 3
- [feedparser](https://pypi.org/project/feedparser/) - RSSフィードの解析
- [pandas](https://pandas.pydata.org/) - データの整形・重複排除
- [openpyxl](https://openpyxl.readthedocs.io/) - Excelファイルの書き込み・装飾

## 使い方

### 1. 必要なライブラリをインストール

```bash
pip install feedparser pandas openpyxl
```

### 2. 実行

```bash
python script.py
```

実行すると、スクリプトと同じフォルダに `news_list.xlsx` が作成（既にあれば更新）されます。

### 3. 定期的に自動実行したい場合

Windowsのタスクスケジューラなどに登録すれば、毎日決まった時間に自動でニュースを収集・蓄積することもできます。

## 出力イメージ

| タイトル | URL | 日付 |
|---|---|---|
| （記事タイトル） | https://... | Sun, 16 Aug 2026 10:00:00 +0900 |

見出し行は太字、各列の幅も読みやすいように自動調整されます。

## 工夫した点

- 実行のたびに古いデータを上書きするのではなく、URLをキーに重複を除外しながら蓄積していく設計にしました
- RSS取得失敗・記事0件・Excelファイルが開いていて保存できない、といった実行時に起こりうるトラブルを想定し、エラーで落ちずにメッセージを表示して安全に終了するようにしました
